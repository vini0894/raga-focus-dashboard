# Description template — LIVE channel format (captured from actual videos 2026-07-06)

Source of truth: pulled from live descriptions (Deep Sleep Surbahar 3hr · Meditation Sarangi · 3hr Bansuri Relaxation) via Data API. Use THIS, not older style notes.

## Structure (in order)

1. **Title-repeat line, slightly extended** — `{Title} of {Outcome phrase}` (e.g. "…| 3 Hours of Peaceful Rest")
2. **Empathy/problem paragraph** — 1-2 sentences, second person, the state the viewer is in
3. **Purpose paragraph** — "This peaceful Indian ambient meditation music is designed to {slow/quiet/release}…"
4. **Content paragraph** — "Enjoy {duration} of {instrument} melodies blended with {tanpura drone, soft ambient textures, …}"
5. **"Perfect for …"** — one sentence, ~10 comma-separated use cases
6. **🎵 ABOUT THIS MUSIC** block:
   - Instrument: / Raga: (YES — name the raga here; live voice includes it) / Style: / Mood: / Atmosphere: / Duration:
7. **🎧 HOW TO USE** — 2-3 sentences, when + how to listen, headphones note
8. **⏱ Chapters / Timestamps** — 10-16 entries, evocative 3-5 word names ("Deep grounding resonance", "Gentle fade into silence"). 1.5hr = clean 10-min marks OK; 3hr = match actual clip boundaries from the merge when known.
9. **⏱ BEST FOR** — 10 short lines (one use case each)
10. **Subscribe line** — "If this music helped you {outcomes}, subscribe to Raga Focus for more uninterrupted Indian ambient healing music."
11. **Hashtags** — 3-6, CamelCase (#DeepSleepMusic #Surbahar #IndianAmbientMusic)

## Voice rules (still apply)
- Accessible, no production-speak, no binaural/Hz specs in viewer-facing text
- No ads promise = REMOVED (false for non-Premium)
- Raga name OK in ABOUT block only — not in the prose paragraphs
